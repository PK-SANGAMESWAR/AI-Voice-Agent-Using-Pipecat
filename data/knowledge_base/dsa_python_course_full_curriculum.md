# Course Overview

**Data Structures & Algorithms in Python — Foundations** is a comprehensive DSA course in Python.

The course is designed to:

- Build strong problem-solving skills from scratch
- Prepare learners for technical interviews
- Support competitive programming preparation
- Create a foundation for advanced Computer Science and Machine Learning topics

The repository contains:

- Structured explanations
- Python implementations
- Curated problem sets
- Important DSA concepts and problem-solving patterns

# Course Curriculum

## 1. Introduction to DSA & Python Basics

Topics include:

- What DSA is and why it matters
- Time and space complexity
- Big-O notation
- Python essentials for problem solving

## 2. Arrays and Lists

Topics include:

- Traversal
- Insertion
- Deletion
- Prefix sums
- Sliding window basics

## 3. Strings

Topics include:

- Character frequency techniques
- Two-pointer approach
- Anagrams
- Palindromes
- Substrings

## 4. Linked Lists

Topics include:

- Singly linked lists
- Doubly linked lists
- Fast and slow pointer technique
- Cycle detection

## 5. Stacks

Topics include:

- Stack implementation
- Valid parentheses

## 6. Queues

Topics include:

- Queue
- Deque
- Circular queue
- Sliding window using deque

## 7. Searching

Topics include:

- Linear search
- Binary search
- Binary search on answer
- Searching in sorted structures

## 8. Sorting

Topics include:

- Bubble sort
- Selection sort
- Insertion sort
- Merge sort
- Quick sort
- Counting sort

## 9. Recursion

Topics include:

- Recursion fundamentals
- Recursion tree
- Common recursion problems

## 10. Hashing

Topics include:

- Hash maps
- Hash sets
- Frequency counting
- Subarray problems
- Substring problems
- Optimized lookups

## 11. Patterns & Problem Solving

Topics include:

- Sliding window
- Two pointers
- Prefix sums
- Fast and slow pointer
- Binary search pattern
- Greedy basics

## 12. Trees

Topics include:

- Inorder traversal
- Preorder traversal
- Postorder traversal
- Binary Search Tree
- N-ary Tree
- Tree Dynamic Programming

## 13. Graphs

Topics include:

- Adjacency matrix
- Adjacency list
- Breadth First Search (BFS)
- Depth First Search (DFS)
- Shortest path algorithms
- Directed Acyclic Graphs (DAGs)
- Disjoint Set Union (DSU)
- Minimum Spanning Tree algorithms
- State Space Graphs
